6. 术语解释

6.1 核心概念

  • 区块链基础

    • 区块链 (Blockchain): 分布式账本技术
    • 共识机制 (Consensus Mechanism): 确保网络一致性的算法
    • 智能合约 (Smart Contract): 自动执行的程序代码
    • 节点 (Node): 网络参与者，维护区块链数据

  • 钱包与安全

    • 钱包 (Wallet): 管理密钥和资产的工具
    • 私钥/公钥 (Private/Public Key): 加密密钥对
    • 助记词 (Mnemonic): 人类可读的密钥备份
    • 交易签名 (Signature): 交易授权机制

  • DeFi 与 NFT

    • 去中心化金融 (DeFi): 基于区块链的金融服务
    • 流动性挖矿 (Liquidity Mining): 提供流动性的奖励机制
    • 非同质化代币 (NFT): 独特的数字资产
    • 质押 (Staking): 参与网络共识的机制

6.2 Web3 开发术语

  • 钱包与账户

    • HD钱包 (Hierarchical Deterministic Wallet): 从单个种子派生多个密钥对的钱包
    • 观察钱包 (Watch-only Wallet): 只能查看余额但不能签名的钱包
    • 多重签名 (Multi-sig): 需要多个私钥共同签名才能执行交易的安全机制
    • 账户抽象 (Account Abstraction): 将账户逻辑从区块链协议中分离的设计模式
    • 社交恢复 (Social Recovery): 通过可信社交关系恢复钱包访问权的机制

  • 交易与签名

    • 交易池 (Mempool): 等待被打包的交易集合
    • 交易哈希 (Transaction Hash): 交易的唯一标识符
    • 签名类型 (Signature Type): 如 EIP-1559、EIP-2930 等不同的交易签名方式
    • 交易重放 (Transaction Replay): 在不同链上重复执行相同交易的安全问题
    • 交易确认 (Transaction Confirmation): 交易被打包进区块并得到网络确认

  • 代币标准

    • ERC-20: 以太坊上最基础的代币标准，定义转账和余额查询接口
    • ERC-721: 以太坊上的 NFT 标准，每个代币都是唯一的
    • ERC-1155: 支持批量转账的多代币标准，适合游戏资产
    • ERC-4626: 代币化保险库标准，用于 DeFi 收益聚合
    • SPL Token: Solana 上的代币标准，支持代币创建和管理
    • TRC-20: TRON 上的代币标准，兼容 ERC-20

  • DApp 协议

    • WalletConnect: 连接移动端钱包和 DApp 的开放协议
    • EIP-1193: 以太坊钱包 Provider 标准接口
    • EIP-6963: 多钱包发现和选择协议
    • EIP-3085: 钱包网络切换请求协议
    • EIP-4361: 签名认证消息标准
    • EIP-712: 结构化数据签名标准

  • 安全与隐私

    • 冷钱包 (Cold Wallet): 离线存储私钥的钱包，提供最高安全性
    • 热钱包 (Hot Wallet): 在线连接的钱包，方便但安全性较低
    • 硬件钱包 (Hardware Wallet): 使用专用硬件设备存储私钥
    • 种子短语 (Seed Phrase): 用于恢复钱包的助记词
    • 密钥派生路径 (Derivation Path): 从种子生成特定密钥的路径
    • 零知识证明 (Zero-knowledge Proof): 证明某个陈述为真而不泄露其他信息的技术

  • DeFi 与 NFT

    • 流动性池 (Liquidity Pool): 用于自动做市商(AMM)的资金池
    • 闪电贷 (Flash Loan): 无需抵押的即时借贷
    • 收益聚合器 (Yield Aggregator): 自动优化收益的 DeFi 协议
    • 元数据 (Metadata): NFT 的链下数据，包含图片、描述等
    • 版税 (Royalty): NFT 二次销售时支付给创作者的费用
    • 地板价 (Floor Price): NFT 集合中最低的挂单价格

  • 跨链与互操作

    • 跨链桥 (Bridge): 连接不同区块链的协议
    • 原子交换 (Atomic Swap): 不同链上资产的安全交换
    • 中继器 (Relayer): 在链间传递消息和数据的服务
    • 预言机 (Oracle): 将链下数据引入区块链的服务
    • 跨链消息 (Cross-chain Message): 在不同链间传递的信息
    • 互操作性标准 (Interoperability Standard): 如 IBC、LayerZero 等跨链协议

  • 开发工具

    • Web3 Provider: 与区块链交互的接口
    • Gas 估算器 (Gas Estimator): 计算交易费用的工具
    • 区块浏览器 (Block Explorer): 查看区块链数据的工具
